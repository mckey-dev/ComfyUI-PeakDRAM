# ComfyUI-PeakDRAM

**更新日: 2026-10-10**

ワークフロー（プロンプト）実行中の **DRAM**・**専用DRAM**・**共有DRAM** のピークを記録し、実行が終わったあと ComfyUI のログに 1 行で出力するカスタムノード拡張です。グラフにノードを置く必要はありません。

## 対象環境

- **OS**: Windows（タスクマネージャーと同系の PDH / DXGI カウンタを使用）
- **ComfyUI**: `PromptExecutor.execute_async` をフックする方式（通常のキュー実行で動作）

Linux / macOS では GPU メモリの計測は行われず、ログに「計測できませんでした」と出ます。

## インストール

このフォルダを ComfyUI の `custom_nodes` に置きます。

```
ComfyUI-ROCm10/custom_nodes/ComfyUI-PeakDRAM/
  __init__.py
  wddm.py
  README.md
```

ComfyUI を再起動してください。起動ログに次の 2 行が出れば読み込み成功です。

```
[PeakDRAM] 実行中のピークを記録し、終了後に DRAM・専用DRAM・共有DRAM をログへ出します
[PeakDRAM] 起動時 | DRAM 17576/48943 MiB | 専用DRAM 179/24517 MiB | 共有DRAM 54/32559 MiB | AMD Radeon RX 7900 XTX
```

`起動時` の行は、拡張が読み込まれた瞬間の **現在値**（ピークではありません）。

## 使い方

1. ComfyUI を起動する
2. いつもどおりワークフローをキュー実行する
3. 実行が終わったら `user/comfyui.log`（またはコンソール）を確認する

サンプリング間隔は **0.1 秒** です。実行中に各項目の最大値を保持し、終了時にそのピークをログへ出します。

## ログの見方

### 起動時

拡張読み込み直後に、DRAM・専用DRAM・共有DRAM の現在使用量と総量が 1 行で出ます（`(+増分)` は付きません）。

### ワークフロー終了時（正常終了の例）

```
[PeakDRAM] prompt=a1b2c3d4-... ok 42.18s | DRAM 28500/48943 MiB (+3200) | 専用DRAM 13200/24517 MiB (+11800) | 共有DRAM 11200/32559 MiB (+9800) | AMD Radeon RX 7900 XTX
```

| 項目 | 意味 |
|------|------|
| `prompt=...` | プロンプト ID |
| `ok` / `error` | ワークフローが成功したか（ノード失敗時は `error`） |
| `42.18s` | 計測開始から終了までの時間 |
| `DRAM 使用/総量 MiB (+増分)` | システム全体の使用中物理メモリのピーク |
| `専用DRAM` | 対象 GPU アダプタの専用 GPU メモリ（タスクマネージャーの「専用 GPU メモリ」に近い） |
| `共有DRAM` | 同アダプタの共有 GPU メモリ |
| 末尾の名前 | 計測した GPU（`torch.cuda` のデバイス名と一致するものを優先、なければ専用容量最大のアダプタ） |

数値は **MiB**（1024² バイト）で、整数に丸めています。`使用/総量` の右側の `(+増分)` は、**そのプロンプト開始直後** からピークまでの差です。

### 計測失敗の例

```
[PeakDRAM] prompt=... ok 1.23s | 計測できませんでした: GPU アダプタまたは性能カウンタを読めません
```

## 既存の VRAM 系拡張との違い

| 種類 | 例 | 主に見ているもの |
|------|-----|------------------|
| PyTorch ベース | ComfyUI-VRAMTools, ProfilerX, performance-report | `torch.cuda` の確保量・ピーク |
| 本拡張 | ComfyUI-PeakDRAM | Windows の **DRAM** と **GPU Adapter Memory**（専用 / 共有） |

共有メモリへ溢れた量をタスクマネージャーに近い目安で見たい場合に向いています。

## ファイル構成

- `__init__.py` — 実行フックのインストールとログ出力
- `wddm.py` — メモリサンプリングとピーク集計

## ライセンス

ComfyUI 本体に合わせて利用してください。必要に応じてリポジトリ側のライセンスを追記してください。
